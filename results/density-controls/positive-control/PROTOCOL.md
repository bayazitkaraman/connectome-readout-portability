# Synthetic sensitivity check

Before scoring, define 24 simulated people and a ten-channel linear delay line. At each time step channel k encodes the input from k time steps before, with independent Gaussian state noise at 0.25 times the target standard deviation. At zero injection all people have the same mapping. At unit injection the first six channels carry a personal sign, stable between visits, and the remaining four channels use the same code for everyone. Allocate balanced +1 and -1 signs by alternating positions in the study's seeded three-partner cycle. For each target, two comparison people then have the opposite code and one has the same code.

Use 2,352 source rows in each paired readout, with equal donor shares or a 25% contribution from the comparison or target's first scan. Identical candidate input/noise realizations make the swap exactly neutral at zero injection. Tune the shared source penalty on common donors only. Use independently generated source, validation, calibration, and test sequences, the production ridge and residual-ridge functions, six calibration draws, four whole-sequence folds and four independent 512-step test sequences. Evaluate 0, 8, 16, 32 and 64 labeled time steps. The primary diagnostic is the zero-label R² gain. Also report the eight-label gain and the first budget sustaining cohort mean R² of 0.50 through 64.

In the population the best linear readout given the person's code has R² = 1/(1+0.25²) = 0.9412. For a balanced bank excluding a pair with opposite signs, an infinitely sampled unregularized fit gives an own-minus-other R² difference of 4 f × 0.6 / (1+0.25²), where f is the fraction of source data assigned to the candidate. Two thirds of pairs have opposite signs. This gives an approximate zero-label average benchmark of 0.065 for the equal share and 0.376 for the 25% share. Equal source allocations can differ by one row in the finite design, and donor-selected ridge changes the expected magnitude. The fixture evaluates whether the pipeline registers a known, large stable signal and what the calibration grid can detect.
