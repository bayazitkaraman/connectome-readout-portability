# Numerical repeat comparison in NKI

Written after inspecting the release schema and counts, before computing graph similarities or decoder outcomes for the perturbed graphs. The wider project had already examined the reference NKI visits and direction halves.

Use all 25 people, both visits, both direction halves, and all 20 sparse input-perturbation Monte Carlo arithmetic (MCA) runs of deterministic tractography. The primary cell is the first visit, odd directions. Report the four-cell mean after giving each person equal weight, plus each cell separately. All cells use their own unperturbed source graph and the original relative ridge penalty of 10, held fixed across conditions. The decoder uses 2,352 source labels and no target fitting labels. The simulated task, gain of 0.9, input map, ten recall delays and four independent test streams of 512 scored time steps follow the previous NKI study.

For each reference source, apply exactly the same fitted decoder and identical fresh test inputs to its own reference, each MCA rerun of that same input, the other unperturbed direction half of the same visit, and the same unperturbed direction half of the other visit. Fix the test key to the source visit for all comparisons so a within-person contrast changes only the wiring in the simulation. Within-visit reference-to-half results must agree with the prior fixed-penalty analysis. For each target graph, calculate its upper-triangle edge-weight Pearson correlation with the 25 reference source graphs in the source visit/half and the rank of the correct person. Record ties explicitly. Also score the average of the 24 unrelated single-person decoders on each graph using that target's identical test signals and the same ridge penalty.

For uncertainty average MCA runs by source, and summarize cells within person before a 10,000-draw participant bootstrap (percentile intervals, seed 20261119). Report the within-cell run standard deviations and participant-level standard deviations/extrema to describe variation. The nominal sample size for uncertainty is 25. Positive and negative controls include an exact graph replay, mean unrelated donor comparison, and replay of selected matching, MCA and half-split scores with an independent state recurrence and SVD ridge fit. The same people recur across cells and the uncertainty conditions on the fixed task, source bank, tested perturbation draws and release. These perturbations model sensitivity to numerical calculations in instrumented libraries after preprocessing. They cannot estimate conventional same-software rerun noise, acquisition variance, or separate components of biological variability.

The local `data/nki/inputs.h5` is the 233,049,104-byte `impactofinstability_connect_dset25x2x2x20_inputs.h5` from Kiar's public release (published MD5 `f457d4a860d79654672143c1ace95ee1`). It contains 2,100 deterministic and 2,100 probabilistic graphs. Only the deterministic rows are used here. The release describes a separate whole-pipeline perturbation file. This analysis concerns the input-perturbation file already present in the project.
