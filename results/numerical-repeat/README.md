# Frozen decoder transfer under numerical perturbations in NKI

For these 25 participants, rerunning deterministic tractography with sparse Monte Carlo arithmetic (MCA) perturbations on the same inputs had little effect on average simulated recall. Changing the direction sample within the acquisition produced a larger loss. Changing visits produced the largest loss. Each comparison holds the decoder, ridge penalty, zero initial state and test signals fixed. All R² values refer to ten simulated recall delays.

The planned primary comparison (first visit, odd directions) had an MCA loss of 0.00034 R² (−0.00065 to 0.00128). Across the four source cells the paired MCA-minus-other-half difference was 0.02434 (0.01682 to 0.03392), and the MCA-minus-other-visit difference was 0.12731 (0.09658 to 0.15957). All 25 participants had a positive value on both contrasts after averaging their cells. An average unrelated decoder scored 0.04212 on the MCA graphs versus 0.18823 for the personal source decoder. ### How much did repeated processing vary?

Of the 2,000 archived MCA runs, 986 had precisely the same off-diagonal weights as the unperturbed graph. Each set of 20 supplied between two and ten distinct edge-weight arrays (median four). The median within-cell SD of own-decoder R² across runs was 0.00185 (range 0.00005 to 0.00930). Across participants the four-cell mean MCA loss ranged from −0.00294 to 0.00358. A follow-up restricted to the 1,014 runs that did change an off-diagonal weight retained all 100 cells and gave a mean loss of 0.00092 (−0.00026 to 0.00202). These estimates cover the released repeats and this ridge penalty and input map. Kiar and colleagues already evaluated graph and feature stability and downstream classification under MCA. The comparison added here measures how much a frozen task decoder loses when reconstruction, direction sample, or visit changes. The selected HDF instruments floating-point inputs to operations in a subset of the original processing libraries after preprocessing. It evaluates the authors’ sparse input-perturbation regime, distinct from ordinary reruns of unchanged software, whole-pipeline perturbation, or repeat scanning. Motion, alignment, processing and possible biological change all contribute to visit differences. The same-visit halves also share preprocessing and nine baseline volumes. ### Reproduction

From the project root, run `python scripts/nki_numerical_repeat.py`. If the original HDF is elsewhere, append `--source PATH`. The script reads the checksummed 233,049,104-byte input-perturbation HDF, the prepared reference NPZ, and the archived fixed-penalty table. Run the analysis in the project environment with pandas’ PyTables HDF support installed. The full analysis took about one minute on this workstation. The published reference source graph and every reported variant use identical fresh inputs keyed to the source visit. This makes all conditions directly paired. Cross-visit scores may differ slightly from earlier results keyed to the target visit.

All 100 unperturbed half-split scores and their changes matched the previous fixed-penalty analysis to 2.1 × 10⁻¹⁶. Independent simulation using direct state recurrence and SciPy SVD verified the personal score and the mean of the 24 other donor scores for 30 test graphs within 2.2 × 10⁻¹⁵. The source-replay control had exactly zero prediction difference. The original source graph data, input seed and task were previously available when this follow-up was designed.
