# Beijing 200-parcel repeat-scan sensitivity

This follow-up analysis was specified before computing the matched-noise contrast on this atlas. It uses all 57 Beijing participants with visit 1 as source and visit 2 as repeat. Use the archived Schaefer-200 cortical parcellation, its seed-10 eight signed input sites, its other 192 readout regions, the native edge weights and the original spectral radius of 0.90. No alternative input maps, direction, atlas or penalty rule will be selected using the test results.

Apply the existing primary linear-recall evaluation without modification. For each person fit the first-visit readout using 2,352 labeled states. Choose its relative ridge penalty among the original 19 candidates by minimizing held-out visit-2 validation MSE from the other 56 participants. The first and repeat graphs receive the same four fresh 512-step test inputs. The primary endpoint is expected source score under size-matched isotropic noise minus measured repeat score. Average the ten delay-specific R² values, then average across people. Use the original 10,000 paired participant bootstrap scheme conditional on the map, signals and tuning panel. Report all 57 results, including failures, along with source, repeat and expected-noise scores, selected penalties, displacement and the number with a positive excess.

Verify source matrix SHA-256 against the archived atlas manifest, participant and visit order against the native Beijing release, and the region weights against the archived cross-resolution site list. Independently check leave-one-person-out selection from the 19 validation errors per person, and compare the unchanged fixed-alpha 1 personal scores to the 57 archived fixed-alpha 1 Schaefer scores. Compare fresh validation losses against the archived atlas losses. Numerical decomposition is checked by the shared primary evaluation. Judge this as one map in one additional cortical atlas. It does not isolate atlas resolution from the differences in the driven regions and cortical coverage relative to the original native atlas.
