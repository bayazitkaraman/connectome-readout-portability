# Training on multiple first-visit reconstructions

This follow-up protocol was recorded before scoring either augmentation. The existing unaugmented repeat-scan findings and the separate target-alignment results were known.

Use all 25 NKI first-visit odd-direction source graphs and the same participants' second-visit odd-direction target graphs. Model, input placement, state warmup, delayed linear recall target (lags 1 to 10) and primary first-to-second-visit evaluation streams follow the archived native pipeline. The Beijing release supplies whole scans only and has no matched first-visit technical reconstruction bank.

Fit three source readouts: one on the odd reference alone, one on that reference and each of its 20 released numerical reruns, and one on the odd and even references of the first visit. The latter are halves of the same acquisition with shared preprocessing. All versions receive the same original training input stream and each version is simulated through the entire stream from its own initial state. Fit on exactly 2,352 rows and the original ten outputs in each condition. Allocate each training time once, with 112 times from each of the 21 numerical graphs or 1,176 from each of the two halves. For each person and arm, permute time indices using NumPy PCG64 with SeedSequence [20261119, 220, zero-based participant index, number of graphs], partition equally in reference-first order (numerical sims 0 through 19), and restore time order for fitting. Preserve all repeated graphs with their specified shares.

Use an unpenalized intercept and one absolute ridge penalty in covariance units per participant in all arms: ten times that participant's mean centered state variance on the original odd-reference training stream. No second-visit labels or states are used to fit or tune. No additional training inputs, target alignment, parameter sweeps, or comparisons between alternative allocations are used.

Evaluate each readout on the original odd reference and the measured odd repeat using the same four independently generated 512-step target-keyed evaluation streams as the archived forward comparison. Report held-out source and repeat mean R² and improvement in repeat R² relative to the unaugmented fit; average the ten delay scores within each participant before averaging participants. For each model also report its ratio of cohort mean repeat R² to its own cohort mean source R². Report the paired change in that ratio (percentage points) and counts improving in absolute repeat R². Use 10,000 paired percentile bootstrap draws of participants with seed 20261120, identical draws across conditions, conditional on the observed runs, inputs and fixed time allocation. Treat the two variants as separate descriptive estimates with pointwise intervals.

Check against the archived source and repeat scores of every participant. As a negative control, assign identical copies of the original graph under each allocation; identical-graph row reconstruction and prediction must agree with the unaugmented fit. Independently solve the three covariance ridge fits as a numerical check. Report absolute repeat-score changes separately from changes in retained share because augmentation can change the source score.
