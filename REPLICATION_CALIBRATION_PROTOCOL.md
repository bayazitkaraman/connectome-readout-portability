# Independent repeat-scan replication

Recorded before scoring this replication. The primary cohort is Beijing Normal University (CoRR BNU1), selected for its published two-session diffusion acquisition, documented visit order, and m2g weighted structural connectomes in a common Desikan-family atlas. Use every participant with two verified, nonidentical diffusion connectomes. Use HCP only as a fallback if session-resolved BNU1 matrices cannot be verified. Select the cohort and atlas from their acquisition and derivative metadata, independently of simulation performance. [Acquisition record](https://fcon_1000.projects.nitrc.org/indi/CoRR/html/bnu_1.html) · [m2g derivatives](https://docs.neurodata.io/m2g/paper/data.html)

Reproduce the [NKI calibration protocol](NKI_CALIBRATION_PROTOCOL.md) within the independent cohort. Freeze the ten delays, eight signed input locations selected with key 10 in the cohort's native ordered atlas, spectral radius 0.90, relative ridge grid and total donor-fitting budget. If atlas labels differ from NKI, retain the original within-atlas input sampling rule and report the difference. Train the personal prior on the same person's first scan, select its transfer penalty using other people's paired scans only, and train the pooled prior on all other people's first scans with donor-only validation. Retain the target-only comparator. Apply a common dataset-specific labelling of participants to the reproducible simulation streams, with disjoint source training, donor validation, target calibration and target test roles. Both visit directions are separate analyses.

The primary direction is the first visit to the second. Give all methods 0, 8, 16, 32, 64, 128, 256, 512 or 2,352 labeled simulated time steps from the target scan. For each positive budget tune a linear correction using only whole-sequence folds inside that budget. Average six independent calibration draws and test on the same new 2,048 steps per target. The primary savings estimate is the pooled minus personal first tested budget where cohort mean R² reaches 0.50 and stays above it at every larger tested budget. If both cross by 128, refine the union of crossing brackets every four steps using identical sequences. Report a zero crossing separately if it occurs; a method that never crosses is censored. Show individuals' paired fewer/equal/more counts and 10,000 participant bootstrap draws conditional on the fitted starting decoders. The paired accuracy endpoint averages the six budgets from 8 through 256, with a practical reference difference of 0.01 R². Thresholds 0.80 and 0.90 and reverse transfer are secondary. Compare the independent cohort with NKI without combining diffusion subsets or visit directions as independent subjects.
