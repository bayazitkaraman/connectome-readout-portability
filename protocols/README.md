# Study protocols

These documents record the questions, choices and scoring rules for each analysis. The opening paragraphs identify which results were already known when each plan was written.

## Decoder transfer and calibration

| Study question | Protocol |
| --- | --- |
| How well does a decoder generalize across people in the initial Lausanne experiment? | [Feasibility study](PROTOCOL.md) and [rewired-network controls](CONTROL_PROTOCOL.md) |
| How well does an NKI participant’s decoder transfer to a second visit? | [Repeat-scan comparison](NKI_RETEST_PROTOCOL.md) |
| Does the first scan reduce the number of labeled target examples needed? | [NKI calibration](NKI_CALIBRATION_PROTOCOL.md) and [Beijing replication](REPLICATION_CALIBRATION_PROTOCOL.md) |
| What does a participant’s first scan add to a pool of other people’s scans? | [Pooled decoder augmentation](POOL_AUGMENTATION_PROTOCOL.md) |
| Is the benefit associated with wiring similarity or connection density? | [Wiring similarity](ANATOMY_ADVANTAGE_PROTOCOL.md) and [density controls](DENSITY_CHECK_PROTOCOL.md) |
| Does transfer improve between direction halves of one acquisition? | [NKI split-half comparison](NKI_SPLIT_HALF_PROTOCOL.md) |
| Can the frozen readout recover the product of three past inputs? | [Nonlinear recall in both cohorts](NONLINEAR_RECALL_PROTOCOL.md) |
