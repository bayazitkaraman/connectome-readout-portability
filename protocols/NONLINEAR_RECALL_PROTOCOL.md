# Prospective nonlinear recall test on the two repeat-scan cohorts

This protocol was written before scoring the nonlinear task. The linear recall findings and donor choices are already known. This is one new task on the same participants.

**Endpoint.** At time t, predict the single continuous quantity u(t−1) × u(t−2) × u(t−3) from the current readout state. These are three different past samples from the original scalar input, not three extra input channels. Use all 25 NKI participants (odd-direction first to odd-direction second acquisition) and all 57 Beijing participants (whole first to whole second scan). Use the original cohort-native node order, input map key 10, tanh reservoir, spectral radius 0.90, simulation seed, and 200-step warm-up. Score ordinary held-out R² against the test target mean. Chance has expected R² near zero; the product's population variance is 1/27.

**Frozen models.** Fit on 2,352 source steps and tune on separate validation streams. Retain the original 19-value relative ridge grid, 10⁻¹⁴ through 10⁴. For single-donor comparisons, choose the transfer penalty using other people's paired visits, excluding the target and the compared donor. Use four independent 512-step role-61 evaluation streams and identical target inputs for all methods. Give a real population decoder the same 2,352 total training steps across the other people and reuse the established donor-disjoint pooling procedure. For the separately fit target-local reference use 2,352 target fitting and 1,176 independent target validation steps. Score the own frozen decoder on its source and target using identical fresh target signals. Relative ridge choices can change by task. No transfer arm may use target outcome labels to fit or tune.

**Comparisons.** Select the closest stranger by Pearson correlation of upper-triangle, off-diagonal edge weights including zeros, without using recall outcomes. The primary estimate is the paired difference in mean R² between that donor and the mean of all other individually fitted donors, evaluated separately by cohort. The other arms are the own first scan, the population decoder, and the target-local fit. Report cohort means, participant wins and paired 95% participant bootstrap intervals (10,000 draws, conditional on the fitted donor bank and test streams). Report closest versus pooled separately. Report the target-local scores first as a learnability check even if transfer is negligible. Keep all participants and report either direction of effect, with no substitution of lags or tasks after scoring.
