# Does including the target person's first scan in a pooled decoder save calibration?

Analysis plan recorded before scoring the augmentation experiment. This is a follow-up to the [independent-cohort replication](REPLICATION_CALIBRATION_PROTOCOL.md). We already know the personal-only, pooled-only and target-only curves from the earlier experiments on these participants. This follow-up tests a different use of the first scan.

## The two pooled decoders

Analyze NKI–Rockland (25 people, original odd diffusion directions) and BNU1 (57 people, whole-scan DKT) separately. The first scan supplies source data and the second supplies target data. For each target person select three unrelated comparison identities without looking at outcomes. Use a random cyclic permutation from the existing simulation generator with keys 172 and cohort size, taking offsets 1, 2 and 3. Each participant serves as a comparison three times. “Unrelated” designates a different participant here; family relationships were not used to select comparators.

For each target/comparison pair the common bank comprises everyone except these two people. Construct two pooled readouts by fitting a linear ridge regression on identical common-bank rows plus rows from one added first scan. One model receives the target person's first scan and one receives the comparison person's first scan. The total source fitting budget is 2,352 time steps in either arm. For the primary comparison distribute them equally across the contributing participants. This gives the added scan 98 examples in NKI and 42 in BNU1. As a prespecified sensitivity analysis, allocate a larger share to the added scan, 588 examples (25%) in either cohort. In both cases divide the remaining rows as evenly as possible among the common donors, identically within each pair. Supply the two candidate scans with the same synthetic source signal, using a dedicated stream, and take the same time indices. The common bank keeps the original participant-specific input sequences. Include a bank-only reference that distributes all 2,352 source rows across the common donors.

For each pair, select a ridge penalty on common first scans alone. Randomize the common donors with keys 173, cohort size, target index and comparison index. Use about two thirds of the common donors to fit the candidate penalties and one third to validate on fresh signals (1,176 validation time steps). Apply the chosen penalty to the final models in both arms and both allocation schemes. Hold the prior task, reservoir, signed input mapping, and target adaptation procedure fixed.

## Target examples and outcomes

Give all arms the same ten delayed-recall targets, four calibration sequences, six calibration draws and four independent 512-step test streams per target as in the [original experiment](NKI_CALIBRATION_PROTOCOL.md). Calibrate each starting decoder separately with the same sequence-blocked ridge procedure. Use 0, 8, 16, 32, 64, 128, 256, 512 and 2,352 labeled time steps and every multiple of four between 32 and 64. If both primary arms cross by 128 with a crossing outside the refined bracket, extend the four-step grid across the relevant coarse bracket.

Average across delays, calibration draws and the three comparison people within each target. Participants receive equal weight. The primary outcome is the first tested budget at which the cohort mean held-out R² reaches 0.50 and stays at least 0.50 at every larger tested budget. Report savings as the comparison-scan budget minus the personal-scan budget. Positive savings favor including the personal scan. Report individual participants' earlier, equal and later crossings, with nonattainment shown separately. The accuracy outcome is personal minus comparison R², averaged equally over 8, 16, 32, 64, 128 and 256 steps. Use 0.01 R² as the practical reference. Estimate uncertainty separately in each cohort with 10,000 paired resamples of participants, holding the fitted models, comparison assignments and simulation streams fixed. Report the fixed 25% analysis alongside the primary result. These outcomes concern simulated recall on MRI-derived structural networks.
