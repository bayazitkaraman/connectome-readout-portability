# Does an individual's frozen decoder transfer across MRI visits?

Written before inspecting NKI decoder scores. Use only the 25-participant two-visit part of Kiar's NKI–Rockland release. Follow the source visit labels. The primary analysis uses native unperturbed deterministic tractography on odd diffusion directions from both visits, trained on visit 1 and tested on visit 2. Repeat the same analysis on even directions and with visits reversed. These checks reuse the same participants. Use the deposited DKT matrix ordering and a reproducible set of eight signed input nodes in this atlas. The map is fixed within NKI. Its anatomical correspondence to the Lausanne input sites is unknown. Audit source data format, labels, symmetry, diagonal handling, isolated nodes and edge weights.

## Simulation and benchmarks

Use the Lausanne conn2res tanh recurrence, spectral radius 0.90, ten recall delays, independent fitting (2,352), validation (1,176) and test (4 × 512) signal samples and ridge grid 10⁻¹⁴ to 10⁴. Fit a readout and select its regularization using only its own source visit. Freeze the weights, intercept and feature order. Apply every visit-1 decoder to every visit-2 target. All candidate decoders for a given target see the identical held-out input sequences and states. Source and target visit streams are distinct. Report an individual readout recalibrated on the target scan as the within-scan reference. Also evaluate a pooled decoder trained exclusively on the other participants' source visits using the same total fit budget and donor-only tuning.

## Analysis and inference

Average the ten lag-specific errors per source–target pair, normalizing by the known input variance. For each target subtract the own-source error from mean other-source error. Positive values favor the same person's first scan. Report mean across participants, median, fraction with a positive advantage, same-person rank among all donors and top-one frequency. Report held-out R² without clipping negative values. For comparison with the strongest structural match, report performance of the other person with the highest Pearson correlation between raw upper-triangle wiring profiles. Compare with target-visit recalibration and pooled transfer to assess practical usefulness.

Use a participant delete-one jackknife that removes both donor and target for a descriptive 95% t interval on the primary mean advantage. Assess matching by 49,999 random one-to-one permutations of participant identity between visits, holding the fitted score matrix fixed, adding one to numerator and denominator. Lags, pairs, diffusion halves and directions of transfer are repeated measurements. Show results by target and summarize by lag. Explicitly report extreme errors and the fraction of other donors beaten so a few unstable decoders cannot masquerade as consistent personal matching.

Pairing on the same target already holds its achievable recall constant. For added value beyond structural similarity, report the number of targets for which the own-source structural correlation lies inside the range of other donors to that target. Where there is support, linearly interpolate other-donor error between the closest correlations on either side. Report a descriptive residual advantage only if at least ten targets have support. Avoid extrapolating a structural adjustment to unmatched people. Report structural and decoder identification ranks separately. Keep later diagnostics distinct from the primary comparison.

## Conditional regularization sensitivity

If the primary self decoder has negative median held-out R² or loses to the pooled decoder for a majority of targets, test one alternative regularization strategy. For every donor–target pair, choose a single relative ridge penalty from the same grid using the mean same-person cross-visit validation error on all remaining identities. Exclude both donor and target from that choice. Fit the final coefficients only on the donor's source-visit training data. Reuse the exact same held-out target streams and report these diagnostic results separately. Hyperparameter selection here has access to repeat scans of other people, which changes the practical training requirements.
